# TSA-WEBMASTERS-26-27
Webmaster

Theme: Artificial Intelligence (AI) learning portal

Challenge: You have been tasked with designing and developing an interactive Artificial Intelligence (AI) learning portal aimed at high school students (grades 9–12). The purpose of this site is to demystify AI by providing a foundational understanding of the technology, showcasing practical tools, and teaching techniques to leverage AI effectively and ethically in an academic setting.

Your website must include the following:

Educational  Content Modules: At least three distinct learning sections covering fundamental AI concepts, practical AI tools/techniques, and ethical AI usage
Gamification & Progress Tracking: An interactive, gamified user interface (e.g., digital badges, experience points, or a progress dashboard) designed to engage students and visually track their completion of the learning modules.

## About this repo

AI learning portal for high school students. TSA Webmaster entry.

## Run it

```bash
npm install
npm run dev
```

`npm test` runs the progress-logic check. `npm run build` type-checks and builds to `dist/`.

## Working on it

Read [AGENTS.md](AGENTS.md) first and give it to your AI tool. It says which folder is yours and the rules that keep the entry legal.

Flow: branch from `main` → work in your folder → open a PR (fill in the AI log) → a different teammate reviews and merges.
